# Understanding domain-specific attribute constraints in multimodal sentiment analysis via ensemble multimodal large language models with structured multistage prompts

- **Citation (IEEE):** R. Chen, J. Tong, X. Zhang, et al., "Understanding domain-specific attribute constraints in multimodal sentiment analysis via ensemble multimodal large language models with structured multistage prompts," *Expert Systems With Applications*, vol. 331, Art. no. 132658, 2026, doi: 10.1016/j.eswa.2026.132658.
- **Domain:** Affective computing / multimodal sentiment analysis with MLLMs
- **Relevance to FYP (1-5):** 3 — unrelated application, but the "modality-specific MLLMs describe each input in text → central LLM reasons with ICL" pipeline is a practical, training-light fusion design for images + tables + documents.

## Problem
Multimodal sentiment analysis research focuses on cross-modal alignment/fusion but neglects how domain-specific attributes (expression domain discrepancy and diversity, cultural, demographic, regional factors, missing modalities) constrain sentiment prediction and generalization.

## Data & modalities
Text, audio and video. 13 benchmarks covering 2 interaction types, 4 tasks and 6 emotional dimensions, e.g., POM, MELD, CMU-MOSI, CMU-MOSEI, SAVEE, CREMA-D, IEMOCAP, MUStARD++, EmoReact; some datasets lack a modality (e.g., MELD audio, SAVEE text), used to study missing-modality effects.

## Method
Ensemble of stage-specific pre-trained MLLMs with structured multi-stage prompts:
- **Stage 1:** Qwen2-Audio (AudioLLM) describes acoustic properties (rhythm, spectral, timbre); VideoLLaMA (VideoLLM) describes facial static/dynamic cues and body movement; modalities temporally synchronized by timestamps; standardized task descriptions generated by ChatGPT; randomized prompt styles.
- **Stage 2:** Llama 3.1 receives the audio/visual text descriptions, task label sets and in-context examples, predicts the emotion class and generates a reasoning description (label augmentation, e.g., valence → calm/neutral/excited).
- **Stage 3:** contrastive positive/negative sample construction to analyse domain-specific attribute constraints via label consistency/inconsistency.
- Missing-modality effect measured via accuracy drop and cue overlap of reasoning descriptions; decoding hyperparameter sweeps (temperature, top-k).

## Results
Reported qualitatively in the abstract/conclusion: the attribute-guided framework is effective across tasks; ablations show audio-only descriptions outperform visual-only on average in their setting, attributed to finer-grained audio prompts; domain attributes (demographic, regional culture) measurably affect classification. (Exact per-dataset numbers not summarised here.)

## Limitations
Relies on frozen general MLLMs (no fine-tuning), so quality depends on the description stage; text bottleneck may lose fine-grained signal; analysis-heavy rather than a single state-of-the-art model; data available only on request.

## Transferable ideas for the FYP pipeline
- **Fusion (late, text-centric):** Stage-1 specialist models convert each modality to text — a VLM describes the cut-part image (edge roughness, dross, burrs), a script summarises machine-database rows (parameter deviations, alarms), RAG returns manual excerpts — then a central LLM reasons over the combined text. Easy to debug and audit.
- **Prompting:** define modality-specific attributes explicitly in the instructions (what visual features to describe), use ICL examples and constrained output format.
- **Evaluation:** run missing-modality ablations (image only / table only / both) and measure accuracy drop plus overlap of cited evidence, to show each modality's contribution.
- **Robustness:** randomize prompt phrasing to avoid prompt-specific overfitting.
